# AI ScamShield

AI ScamShield is an explainable AI-based system designed to detect and assess digital scam risks, including phishing, digital arrest, banking/KYC, investment, job, payment, and other financial scams.

## Project Objective

The system aims to:

- Detect potentially suspicious digital content
- Classify the likely scam category
- Calculate a risk score
- Explain the detected warning signals
- Analyze suspicious URLs
- Provide actionable safety guidance

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- Matplotlib
- Streamlit
- Power BI
- Git & GitHub
